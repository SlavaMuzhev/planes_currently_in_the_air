# Planes Currently in the Air ✈️

Проект по сбору и анализу данных о самолетах, находящихся в воздушном пространстве выбранных стран 
в режиме реального времени. Данные собираются из открытых API и сохраняются в базу данных PostgreSQL 
для последующего анализа.

## 🚀 Основной функционал
- Получение географических координат (bounding box) стран через **Nominatim (OpenStreetMap)**.
- Сбор данных о полетах (ICAO24, позывные, скорость, высота) через **OpenSky Network API**.
- Хранение данных в реляционной БД **PostgreSQL** с соблюдением связей (Foreign Keys).
- Аналитическая выборка данных: расчет средней скорости, поиск по авиакомпаниям, 
фильтрация быстрых судов.

## 🛠 Технологии
- **Python 3.x**
- **PostgreSQL**
- **Библиотеки**: `requests`, `psycopg2-binary`, `python-dotenv`.
- **Архитектура**: Соблюдение принципов SOLID, использование абстрактных классов и модульности.

## 📋 Инструкция по запуску

### 1. Подготовка базы данных
Убедитесь, что у вас установлен PostgreSQL и запущен сервер. Создайте базу данных (например, `postgres`).

### 2. Настройка окружения
Создайте в корне проекта файл `.env` на основе примера:
```env
DB_NAME=postgres
DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5433
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
```bash
python main.py
```

## 📊 Структура проекта
- `src/base_api_adapter.py` — абстрактный класс для работы с API (соблюдение SOLID).
- `src/api_adapter.py` — реализация работы с внешними сервисами (Nominatim, OpenSky).
- `src/db_manager.py` — класс для взаимодействия с PostgreSQL.
- `main.py` — основной скрипт управления (оркестратор).

## ⚠️ Примечание
Для корректной работы с API Nominatim в коде используется заголовок `User-Agent`. 
Для получения актуальных данных по большим странам (например, США или Россия) программа автоматически 
обрабатывает координаты, полученные из API
